dependencies
------------

- postgresql
- python3
- php8.1
- apache2
- PEAR package: html_quickform2

### PHP Extensions (Required for database connectivity)

On Fedora/RHEL systems, install these packages:

```bash
sudo dnf install php-pdo php-pgsql
```

On Debian/Ubuntu systems:

```bash
sudo apt-get install php-pdo php-pgsql
```
